# Admin PWA Installability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the admin app installable on all platforms (Android/Chrome, iOS/Safari, desktop) as a PWA with a home-screen/desktop icon that launches `/admin` standalone.

**Architecture:** Single Vite SPA gets `vite-plugin-pwa` (Workbox generateSW). The build emits a web manifest (admin-focused: `start_url: /admin`, `display: standalone`) and a self-updating service worker that precaches the hashed app shell only — not the 3.3MB of marketing images in `public/images/` — and never caches Supabase API calls. A `useInstallPrompt` hook powers a conditional "Install app" action in the admin sidebar. Design spec: `docs/superpowers/specs/2026-09-22-admin-pwa-design.md`.

**Tech Stack:** React 19, Vite 6, vite-plugin-pwa (new dev dep), Workbox, Vitest + @testing-library/react 16.3.2 (has `renderHook`), Python/PIL (one-time icon generation, available on this machine).

**Conventions:** Tests live next to source files as `*.test.jsx`. Commits use conventional format like `feat(admin): ...`. Never edit `.worktrees/` — all paths are in the main checkout.

**Files:**

- Create: `public/icons/pwa-192.png`, `public/icons/pwa-512.png`, `public/icons/pwa-maskable-192.png`, `public/icons/pwa-maskable-512.png`, `public/icons/apple-touch-icon.png`

- [ ] **Step 1: Write the icon generation script**

Create `scripts/generate-pwa-icons.py`:

```python
#!/usr/bin/env python3
"""Generate PWA icons from src/assets/logo.png into public/icons/."""
from pathlib import Path

from PIL import Image

BRAND_GREEN = (0, 107, 60, 255)  # #006B3C
ROOT = Path(__file__).resolve().parents[1]


def export(logo, size, path, pad_ratio):
    canvas = Image.new("RGBA", (size, size), BRAND_GREEN)
    inner = round(size * pad_ratio)
    scaled = logo.resize((inner, inner), Image.LANCZOS)
    canvas.alpha_composite(scaled, ((size - inner) // 2, (size - inner) // 2))
    canvas.convert("RGB").save(path, "PNG")
    print(f"wrote {path} ({size}x{size}, logo at {pad_ratio:.0%})")


def main():
    logo = Image.open(ROOT / "src/assets/logo.png").convert("RGBA")
    out = ROOT / "public/icons"
    out.mkdir(parents=True, exist_ok=True)

    for size in (192, 512):
        export(logo, size, out / f"pwa-{size}.png", 0.85)
    for size in (192, 512):
        export(logo, size, out / f"pwa-maskable-{size}.png", 0.55)
    export(logo, 180, out / "apple-touch-icon.png", 0.85)


if __name__ == "__main__":
    main()
```

Rationale: every icon gets a solid `#006B3C` background (iOS rejects transparent apple-touch-icons; Android launcher backgrounds vary). Maskable logos sit at 55% so the artwork stays inside the 40%-radius safe-zone circle (a 0.55 square has a 0.39 half-diagonal < 0.40 radius).

import { describe, expect, it, vi } from 'vitest'
import { act, renderHook } from '@testing-library/react'
import useInstallPrompt from './useInstallPrompt.js'

function makeInstallEvent(outcome = 'accepted') {
  const event = new Event('beforeinstallprompt', { cancelable: true })
  event.prompt = vi.fn()
  event.userChoice = Promise.resolve({ outcome })
  return event
}

describe('useInstallPrompt', () => {
  it('captures beforeinstallprompt and exposes canInstall', () => {
    const { result } = renderHook(() => useInstallPrompt())
    expect(result.current.canInstall).toBe(false)

    const event = makeInstallEvent()
    act(() => {
      window.dispatchEvent(event)
    })

    expect(result.current.canInstall).toBe(true)
    expect(result.current.promptInstall).toBeInstanceOf(Function)
  })

  it('prompts once, reports the outcome, and clears the offer', async () => {
    const { result } = renderHook(() => useInstallPrompt())
    const event = makeInstallEvent()
    act(() => {
      window.dispatchEvent(event)
    })

    let accepted
    await act(async () => {
      accepted = await result.current.promptInstall()
    })
    expect(event.prompt).toHaveBeenCalledTimes(1)
    expect(accepted).toBe(true)
    expect(result.current.canInstall).toBe(false)

    expect(event.prompt).toHaveBeenCalledTimes(1)

- [ ] **Step 3: Write the hook**

Create `src/hooks/useInstallPrompt.js`:

```js
import { useCallback, useEffect, useState } from 'react'

export default function useInstallPrompt() {
  const [deferredPrompt, setDeferredPrompt] = useState(null)

  useEffect(() => {
    const onBeforeInstallPrompt = (event) => {
      event.preventDefault()
      setDeferredPrompt(event)
    }
    window.addEventListener('beforeinstallprompt', onBeforeInstallPrompt)
    return () => window.removeEventListener('beforeinstallprompt', onBeforeInstallPrompt)
  }, [])

  const promptInstall = useCallback(async () => {
    if (!deferredPrompt) return false
    deferredPrompt.prompt()
    const { outcome } = await deferredPrompt.userChoice
    setDeferredPrompt(null)
    return outcome === 'accepted'
  }, [deferredPrompt])

  return { canInstall: Boolean(deferredPrompt), promptInstall }
}
```
